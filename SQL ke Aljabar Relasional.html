SQL ke aljabar relasional

Tulis query SELECT, ekspresi dan pohon operatornya langsung muncul.

Ekspresi aljabar

Pohon operator

    Didukung: SELECT, DISTINCT, JOIN (inner, left, right, full, natural, cross), WHERE, GROUP BY, HAVING, ORDER BY, LIMIT/OFFSET, UNION, INTERSECT, EXCEPT, WITH (CTE), CASE, CAST, serta IN, NOT IN, EXISTS di WHERE. CTE dan subquery skalar ditulis sebagai definisi terpisah (S1, S2, dan seterusnya) yang di-join ke query utama. SQL memakai bag semantics (duplikat boleh), sedangkan aljabar relasional murni memakai set.
